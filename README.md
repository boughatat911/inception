Description
A minimal Docker Compose stack for the Inception project: Nginx (TLS), WordPress (php-fpm), MariaDB.

Instructions
1. Copy srcs/.env.example to srcs/.env and fill real credentials (DO NOT commit srcs/.env).
2. Run: make all
3. Open: https://<login>.42.fr (replace <login> with the evaluated student's login)

Resources
AI usage: small scripts and templates were assisted by an AI agent; all Dockerfiles, scripts, and configuration were written/approved by the student.
